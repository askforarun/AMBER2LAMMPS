# Research use and adoption

JOSS requires demonstrated research use; anticipated future usefulness is not
enough. This file is the public record for verifiable AMBER2LAMMPS use cases.

## Evidence required for each use case

Add only information that the authors or users can verify:

- project or study title;
- research group or institution;
- system converted and AMBER-family force fields used;
- how the generated LAMMPS model was used;
- software version or Git commit;
- public paper, preprint, dataset, workflow or repository URL, when available;
- contact or acknowledgement permission for non-public work; and
- the independent user who reproduced installation or conversion.

## Documented uses

No research-use claim has yet been added to this repository. Before JOSS
submission, the maintainers must document at least one real research workflow
and should obtain an independent-user installation/conversion report. Do not
replace this statement with an aspirational example.
