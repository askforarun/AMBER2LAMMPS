# InterMol/LAMMPS epon validation bundle

This folder is a self-contained LAMMPS energy comparison for the repository's
`epon.prmtop`, `epon.crd`, and `epon.pdb` source files. It contains the existing
validation snapshots that previously lived at the repository root; they were
moved here to keep one authoritative set rather than duplicate the files.

## Contents

- `intermol/epon_intermol.lmp` and `intermol/epon_intermol.input`: output and
  runnable LAMMPS input generated by InterMol.
- `amber2lammps/epon_validation.data`, `epon_validation.parm`, and
  `epon_validation.input`: output and runnable LAMMPS input generated by
  AMBER2LAMMPS.
- `expected_energies.json`: expected `run 0` energies, the topology charge, and
  the component-specific acceptance tolerances used by CI.

Both data files use the same InterMol simulation cell. AMBER2LAMMPS is given the
raw topology charge (`-0.0029959956756283254 e`) so that neither converter
normalizes charge. This makes the comparison test force-field conversion rather
than the separately tested `--charges` feature.

## Run the committed files

Use LAMMPS built with `MOLECULE`, `EXTRA-MOLECULE`, and `KSPACE`. CI uses commit
`26e5f79b4e5aa77b65fc4fbf314b206bf0530b45`, tagged
`stable_22Jul2025_update1`.

From this directory:

```bash
cd intermol
lmp -in epon_intermol.input -log none

cd ../amber2lammps
lmp -in epon_validation.input -log none
```

Compare the first thermo row from each command with `expected_energies.json`.
The validation requires absolute differences no larger than the stored
tolerance for every energy component.

## Regenerate and verify everything

Install this repository and InterMol's dependencies, then check out InterMol at
the CI-pinned commit:

```bash
python -m pip install -e .
git clone https://github.com/shirtsgroup/InterMol.git /tmp/InterMol
git -C /tmp/InterMol checkout 7125764d42f6e6c589dc2d1df71e3e812b3a7b27
python -m pip install "parmed==4.3.0" "six==1.17.0"
```

From the repository root, run the same end-to-end comparison used in CI:

```bash
python validation/validate_intermol.py \
  --intermol-dir /tmp/InterMol \
  --lammps "$(command -v lmp)"
```

To export a freshly generated bundle to an empty directory for inspection, add
`--artifacts-dir /tmp/intermol-epon-results`. The validator refuses to overwrite
a non-empty artifacts directory.
